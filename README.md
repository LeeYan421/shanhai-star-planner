# 梧桐山海

妄想山海工具箱，安卓当前版本 **1.3.7**，包含离线星宿配置、变异速查、蚩尤旗兵魂、巨兽刷新时钟和悬浮时钟。另提供Windows x64绿色版。

输入星宿点，选择武器天赋、四元素目标与优先规则，生成满足前置条件的加点方案。支持多套方案、武器与方位定位、属性行号指导和手动悬浮进度。

- 暴击优先：暴击 → 攻击。
- 自定义目标：暴击达到指定增量后让攻击最高，同收益少耗点。
- 攻击穿透优先：攻击 → 穿透 → 暴击。
- 虚战优先：固定自选天赋，再补充满级Lv6天赋，最大化节点与携带天赋总参考战力，包含元素。

变异速查支持按巨兽、部位、特质、年份组合筛选，查看攻击／穿透档位、具体数值及来源；另可检索斗兽特质、蜃兽特性与全部词条。不包含宠物搭配推荐。

蚩尤旗兵魂速查收录40种兵魂、918个去重宠物名称，支持兵魂反查核心宠物、宠物查兵魂及名称和效果搜索。不记录宠物年份，同名记录的兵魂关联合并保留，具体个体以游戏魂力页核对。

加点指导按星宿合并步骤，保留公共前置顺序和已有勾选进度。悬浮总览自动分栏显示各属性目标等级及“不点”的行，逐级收益和战力参考在明细中查看。

四元素分为8个具体星宿，按游戏属性行设置0～6级，前置自动补齐，四种规则均可使用。支持天赋点数、升级玉／纹与单项每点战力明细，另有收藏、最近查询、方案对比、备份、攻略卡和离线方案码。

悬浮时钟提供三种数字预设，可自定义文字、背景与描边颜色，拖动移动、双指自由缩放、长按关闭。反馈与需求投票使用独立服务；日志仅由用户主动提交，用户侧不展示正文，不附带设备信息或星宿方案。

巨兽刷新时钟支持按年份和名称选择头像，自选时长、多只独立计时、常用收藏及到时提醒。

Windows x64绿色版现已提供，解压全部文件后运行“梧桐山海.exe”。保留离线计算、兵魂及变异速查、置顶指导和透明时钟；方案备份可与安卓互通。需要.NET Framework 4.8和Microsoft Edge WebView2。

## 检查更新

启动时静默检查一次，发现新版才弹窗；也可打开「帮助 → 检查更新」主动检查。多个更新入口自动容错；点击下载后在App内获取安装包并自动换线，校验通过后交系统确认安装。星宿计算、图鉴与已保存方案均可离线使用。

更新清单经过签名校验，安装包下载后另行核验大小、SHA-256、包名、版本与应用签名。下载入口固定指向本仓库。各网络的连通性可能不同，线路不可用时可换线或稍后重试。

## 本版变化

新增
• 巨兽刷新时钟：选择头像和时长开始计时，支持年份筛选、名称搜索、常用收藏、多只独立计时，以及到时弹窗和振动提醒。

优化
• 全部页面采用 MDUI 2 组件，首页工具卡片改为居中正方形布局。
• 悬浮时钟开关移至上方，配置支持折叠，大小改为滑块调节并显示百分比。
• 悬浮指导布局更紧凑，悬浮球支持贴边隐藏。

修复
• 修复手机下拉选项显示不全、页面误触双指缩放和攻略卡显示异常。
• 修复悬浮窗拖动不跟手、白色底边和变异悬浮速查异常放大。
• 修复巨兽目录遗漏与年份不准确，补齐千年以上巨兽狩猎图鉴。
• 修复调整时钟其他设置时，小数缩放比例被改变的问题。

## 使用提示

本工具独立运行，不读取或修改游戏数据。战力为静态属性计分参考，不包含角色额外倍率及状态，实际以游戏显示为准。悬浮指导需手动授予系统悬浮窗权限。

本仓库提供安装包和版本更新信息。
